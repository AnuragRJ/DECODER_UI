# Architecture

Architecture documents for the Python Argo decoder.

Files in this directory describe canonical architectural decisions and stay in
sync with the codebase.

- `architecture.md` — target architecture, layers, dependency rule.
- `metadata.md` — central metadata registry and loader protocol.
- `decoder_table.md` — firmware-version routing table (tables-not-code).
- `platforms.md` — platform plugin interface, dispatch flow, Provor SBD plugin.
- `oracle_harness.md` — dual-run harness and comparator.
- `versioning.md` — release, tag, and compatibility policy.

Documents are updated as part of every phase's Definition of Done.
