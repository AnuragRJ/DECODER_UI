# API Reference

Public Python API documentation.

The decoder can be consumed as a Python library (not only as a CLI). All
modules under `argo_decoder.api` and any module explicitly re-exported from
`argo_decoder/__init__.py` are considered public. Internal modules
(underscored files, or modules outside `api/`) may change between minor versions.

Contents are auto-generated from docstrings by `mkdocstrings`; this directory
may additionally contain narrative API documentation.
